# jgoneit/homebrew-tap

[jaekit](https://github.com/jgoneit/jaekit)의 Homebrew tap입니다.

```bash
brew install jgoneit/tap/jaekit
```

```bash
ha --version
```

`ha 0.1.1`이 나오면 됩니다.

| Formula | 설치하는 것 |
| --- | --- |
| `jaekit` | Seal Core 실행 파일 `ha`. 태그의 Release에서 자기 플랫폼(macOS·Linux × arm64·amd64) 파일을 받아 checksum을 확인하고 설치합니다. Go나 빌드가 필요 없습니다 |

Spec·Seal plugin 설치, 업데이트·제거, v0.1.1의 한계는 [jaekit README](https://github.com/jgoneit/jaekit#설치)에 있습니다.
