# jgoneit/homebrew-tap

[jaekit](https://github.com/jgoneit/jaekit)의 Homebrew tap입니다.

```bash
brew install jgoneit/tap/jaekit
ha --version    # ha 0.1.0
```

| Formula | 설치하는 것 |
| --- | --- |
| `jaekit` | Seal Core 실행 파일 `ha`. 태그의 소스를 brew의 Go로 빌드합니다 |

Spec·Seal plugin 설치와 v0.1.0의 한계는 [jaekit README](https://github.com/jgoneit/jaekit#설치)에 있습니다.
