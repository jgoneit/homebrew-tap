# jgoneit/homebrew-tap

[jaekit](https://github.com/jgoneit/jaekit)의 Homebrew tap입니다.

```bash
brew install jgoneit/tap/jaekit
ha --version
```

현재 버전은 `ha 0.1.3`입니다. 기존 설치는 `brew update` 후 `brew upgrade jaekit`으로 갱신합니다.

| Formula | 설치하는 것 |
| --- | --- |
| `jaekit` | Seal Core 실행 파일 `ha`, 공개 문서, 선택적으로 사용할 참조 검사와 예시. macOS·Linux × arm64·amd64 Release 파일을 받아 checksum을 확인합니다. Go 빌드가 필요 없습니다. |

문서와 참조 자료는 `$(brew --prefix jaekit)/share/jaekit`에 있습니다. Python 3은 참조 검사를 선택할 때만 필요합니다.

Spec·Seal 플러그인 설치, 업데이트·제거는 [v0.1.3 설치 안내](https://github.com/jgoneit/jaekit/blob/v0.1.3/guides/INSTALL.md)를 참고하세요.
